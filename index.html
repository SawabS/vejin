Bêyta Dilîبەیتا دلی

by Feqiyê Teyran (1590 to 1660)Kurmanji · Behdinî

Eighty-four stanzas addressed to a sleeping heart. Feqiyê Teyran, the earliest Kurdish poet whose name and voice survive intact, spends the whole poem shaking one listener awake: the world turns, the evening has already come, and the heart is still dozing. The refrain returns each time on the same open -are rhyme, so the argument advances while the sound stays put.
